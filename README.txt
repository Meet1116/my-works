伍诗怡｜AIGC 视频设计师互动作品集

打开方式：
1. 用 VS Code 打开整个 AI-Creator-Portfolio-Wu-Shiyi-Interactive 文件夹。
2. 在 videos 文件夹放入 7 个 mp4 视频。
3. 视频文件名必须是：
   ai-manju-01.mp4
   ai-manju-02.mp4
   ai-manju-03.mp4
   ai-dialogue.mp4
   game-video.mp4
   ae-motion.mp4
   ai-ad.mp4
4. VS Code 安装 Live Server 后，右键 index.html → Open with Live Server。

新增交互：
- 作品分类筛选
- 点击 OPEN 打开大屏视频
- 点击圆形按钮播放/暂停
- 双击视频区域打开大屏
- 鼠标跟随效果
- 滚动入场动画
- 移动端汉堡菜单
- 彩色渐变、动态装饰和滚动文字
